# 商品推广工作流的平台接入说明

来源：用户提供的 `dsh-product-promo.zip`。

平台执行器入口：`backend/src/modules/workflows/product-promo-workflow.ts`。

为保证云端运行隔离，平台版本做了以下适配：

- 移除了原实现中的个人电脑绝对路径扫描；
- 默认不再读取运行账户目录下的 `~/.dsh/.credentials.yaml`；
- 模型密钥、FFmpeg 与 TTS 路径仅通过服务端受控环境变量注入；
- 用户素材从 OSS 下载到任务专属目录，输出再上传回 OSS；
- 每个任务由服务端计算额度、预留额度、失败释放额度；
- 同一服务进程默认串行执行一个商品推广任务，避免 FFmpeg 抢占资源。

工作流依赖：Python 3、FFmpeg；TTS 组件和封面模型为可选能力。未配置模型密钥时，脚本会采用离线文案模板；未配置 TTS 时会降级为静音草稿，平台状态接口会提示基础运行条件。
